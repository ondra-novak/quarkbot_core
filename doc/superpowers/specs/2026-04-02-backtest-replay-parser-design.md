# Backtest Replay Parser — Design Spec

**Date:** 2026-04-02
**Status:** Approved

## Overview

A standalone C++ library for reading and writing backtest replay data. The library defines a single canonical binary file format (`.qkrp`) for high-volume tick/event data, a companion JSON metadata file, and a set of converters from common external sources (CSV-OHLC, CSV-Tick, JSON exchange dumps).

This library replaces the existing `Replay` namespace in `src/simulator/` and is intended as the foundation for the refactored backtest infrastructure.

---

## File Format

### Binary Replay File (`.qkrp`)

A self-contained, sequentially-readable binary file. All multi-byte integers are little-endian. Doubles are IEEE 754 little-endian.

#### File Header (12 bytes)

| Offset | Size | Field     | Value              |
|--------|------|-----------|--------------------|
| 0      | 8    | magic     | `"QKRPLAY\0"`     |
| 8      | 1    | version   | `uint8_t = 1`     |
| 9      | 3    | reserved  | zeros              |

#### Record Layout (variable length, sequential)

| Offset | Size         | Field        | Description                                      |
|--------|--------------|--------------|--------------------------------------------------|
| 0      | 4            | record_len   | `uint32_t` — total bytes of record, inclusive    |
| 4      | 1            | type         | `uint8_t` — event type (see below)               |
| 5      | 8            | timestamp    | `int64_t` — microseconds since Unix epoch        |
| 13     | 2            | symbol_len   | `uint16_t` — byte length of symbol string        |
| 15     | symbol_len   | symbol       | UTF-8, no null terminator                        |
| 15+N   | varies       | payload      | type-specific (see below)                        |

#### Event Types and Payloads

| Type | Name                | Payload                                                                 |
|------|---------------------|-------------------------------------------------------------------------|
| 0x01 | Trade               | `double price, size`                                                    |
| 0x02 | Quote               | `double bid, bid_size, ask, ask_size`                                   |
| 0x03 | ClosedBar           | `double open, high, low, close, volume; uint32_t interval_sec`          |
| 0x04 | OrderBookSnapshot   | `uint16_t count; count × {double price, double size, uint8_t side}`     |
| 0x05 | OrderBookDelta      | `double price, double size (0=remove); uint8_t side (0=bid, 1=ask)`     |

Unknown type values must be skipped using `record_len` (forward compatibility).

---

### Companion Metadata File (`.qkrp.json`)

A plain JSON file placed alongside the binary. Optional but strongly recommended — the binary file is fully self-contained without it. The companion can always be regenerated by scanning the binary.

```json
{
  "version": 1,
  "total_events": 4812903,
  "time_start": "2024-01-01T00:00:00.000Z",
  "time_end":   "2024-03-31T23:59:59.999Z",
  "symbols":    ["BTCUSDT", "ETHUSDT"],
  "event_types": ["trade", "quote", "closed_bar"]
}
```

The `event_types` field uses the lowercase string names: `"trade"`, `"quote"`, `"closed_bar"`, `"orderbook_snapshot"`, `"orderbook_delta"`.

## Library API

All symbols live in the `quarkbot` namespace. The library is header+source, no external dependencies beyond the C++20 standard library.

### Event Types

```cpp
using tp_t = std::chrono::system_clock::time_point;

struct TradeEvent {
    std::string_view symbol;
    tp_t time;
    double price, size;
};

struct QuoteEvent {
    std::string_view symbol;
    tp_t time;
    double bid, bid_size, ask, ask_size;
};

struct ClosedBarEvent {
    std::string_view symbol;
    tp_t time;
    double open, high, low, close, volume;
    uint32_t interval_sec;
};

struct OBLevel {
    double price, size;
    bool is_bid;
};

struct OrderBookSnapshotEvent {
    std::string_view symbol;
    tp_t time;
    std::span<const OBLevel> levels;
};

struct OrderBookDeltaEvent {
    std::string_view symbol;
    tp_t time;
    double price, size;  // size == 0 means remove level
    bool is_bid;
};

using Event = std::variant<
    TradeEvent, QuoteEvent, ClosedBarEvent,
    OrderBookSnapshotEvent, OrderBookDeltaEvent
>;
```

`symbol` and `levels` in returned events are views into the reader's internal buffer. They are valid only until the next call to `next()`.

### ReplayReader

```cpp
class ReplayReader {
public:
    explicit ReplayReader(std::string_view path);    // opens file, reads header
    explicit ReplayReader(std::istream &stream);     // stream-based, no companion file read

    std::optional<Event> next();  // returns nullopt at EOF
    void reset();                 // seeks back to first record (file-based only)
};
```

Throws `std::runtime_error` on malformed header or unsupported version. Unknown record types are silently skipped.

### ReplayWriter

```cpp
class ReplayWriter {
public:
    explicit ReplayWriter(std::string_view path);   // opens .qkrp, writes .qkrp.json on close
    explicit ReplayWriter(std::ostream &stream);    // stream-only, no companion file

    void write(const Event &event);
    void close();  // flushes binary, writes companion JSON if path-based
    ~ReplayWriter(); // calls close() if not already closed
};
```

The writer tracks event count, min/max timestamps, symbols seen, and event types seen in order to populate the companion JSON on `close()`.

## Converters

### Interface

```cpp
class IConverter {
public:
    virtual void convert(std::istream &in, ReplayWriter &out) = 0;
    virtual ~IConverter() = default;
};
```

### CsvOhlcConverter

Reads CSV files with OHLCV data. Produces `ClosedBarEvent` records.

Expected columns (names configurable): `time, open, high, low, close, volume`.
Timestamp column accepts: Unix epoch (seconds or milliseconds, auto-detected), or ISO 8601 string.

Configuration:
```cpp
struct CsvOhlcConfig {
    std::string symbol;           // symbol to assign (not in file)
    uint32_t interval_sec = 60;   // bar interval in seconds
    // column name overrides
    std::string col_time   = "time";
    std::string col_open   = "open";
    std::string col_high   = "high";
    std::string col_low    = "low";
    std::string col_close  = "close";
    std::string col_volume = "volume";
};
```

### CsvTickConverter

Reads CSV tick files. Produces `TradeEvent` and optionally `QuoteEvent` records.

Required columns: `time, price, size`. Optional columns: `bid, ask, bid_size, ask_size` — if all four are present, a `QuoteEvent` is emitted alongside each `TradeEvent`.

Also handles the existing mmbot replay CSV format (`timestamp, symbol, bid, ask, bid_size, ask_size, trade, volume, index`).

Configuration:
```cpp
struct CsvTickConfig {
    std::string default_symbol;   // used if no symbol column present
    std::string col_time    = "time";
    std::string col_symbol  = "symbol";   // empty = use default_symbol
    std::string col_price   = "price";
    std::string col_size    = "size";
    std::string col_bid     = "bid";
    std::string col_ask     = "ask";
    std::string col_bid_size = "bid_size";
    std::string col_ask_size = "ask_size";
};
```

### JsonExchangeConverter

Reads NDJSON (newline-delimited JSON) or a JSON array. Each object is mapped to an event via a configurable field map. Intended for handling raw exchange API dumps (e.g., Binance trade history, order book snapshots).

The event type is determined by a required `"type"` field (or a configurable field name), with values mapped to internal event types via a user-supplied map.

Configuration:
```cpp
struct JsonFieldMap {
    std::string field_type     = "type";
    std::string field_symbol   = "symbol";
    std::string field_time     = "time";    // expects ms epoch integer or ISO string
    std::string field_price    = "price";
    std::string field_size     = "size";
    // ... bid/ask/levels as needed
    std::map<std::string, std::string> type_map;  // e.g. {"aggTrade" -> "trade"}
};
```

## Error Handling

- `ReplayReader` constructor throws `std::runtime_error` for: file not found, bad magic, unsupported version.
- Unknown record types are skipped silently (forward compatibility via `record_len`).
- Converters throw `std::runtime_error` for missing required columns or unparseable data.
- `ReplayWriter` throws on write failure.

---

## Out of Scope

- Compression (e.g., zstd) — can be layered on top via a compressed stream
- Multi-file / sharded datasets — caller concatenates or wraps multiple `ReplayReader`s
- Random access / time-range seeking — sequential read only; seeking requires an external index
- Network streaming sources — converters operate on `std::istream` only
